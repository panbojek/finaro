# Zmiany i zgłoszenia

Kod źródłowy: [panbojek/finaro](https://github.com/panbojek/finaro). Błędy i propozycje zgłaszaj w [Issues](https://github.com/panbojek/finaro/issues), a zmiany kodu w [Pull requests](https://github.com/panbojek/finaro/pulls). Dostęp do prywatnego repozytorium wymaga uprawnień.

Opisz problem lub potrzebę jednym przykładem. Zgłoszenie błędu powinno zawierać wersję Windows i Node, kroki odtworzenia oraz fikcyjne dane. Nie dołączaj prawdziwych portfeli ani sekretów.

Przy zmianie kodu zachowaj izolację demo, walidację i potwierdzanie usuwania. Uruchom npm test, sprawdź ręcznie zmieniony przepływ i zaktualizuj właściwą instrukcję. W opisie zmian wskaż wynik i ograniczenia sprawdzeń. Nie dodawaj automatycznej telemetrii, kont lub płatnych integracji bez uzgodnienia.
