# Kod aplikacji

Repozytorium i pełna paczka: [panbojek/finaro](https://github.com/panbojek/finaro). [Zgłoszenia problemów](https://github.com/panbojek/finaro/issues).

Uruchom **Uruchom-Finaro.cmd** w Eksploratorze Windows. Wymagany Node.js 24 LTS. Otworzy się lokalne Finaro demo na http://127.0.0.1:47832, z fikcyjnym portfelem i bez klucza API.

Pełna dokumentacja znajduje się poziom wyżej: [README](../README.md), [instalacja](../docs/INSTALACJA.md), [instrukcja](../docs/INSTRUKCJA.md), [rozwój](../docs/ROZWOJ.md).

Nie kopiuj samego folderu kod. Loader potrzebuje także demo/portfolio.json, a dystrybucja powinna zachować dokumentację oraz licencję.
